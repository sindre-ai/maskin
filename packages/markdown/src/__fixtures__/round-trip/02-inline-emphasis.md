# Inline formatting

A paragraph mixes *italic*, **bold**, and `inline code` with a [link](https://maskin.io).

The reader should see **bold containing `code`**, *italic containing [a link](https://example.com)*, and `code containing *asterisks*` all round-trip untouched.

An external link like [Maskin docs](https://maskin.io/docs "docs title") keeps its title attribute.
