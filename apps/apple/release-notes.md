# 1.2

- iPad: one simple navigation. The sidebar is gone, your avatar is on every screen, and each screen has a single + button.
- Join a workspace from an invite link and create your account without leaving the app.
- Attach files up to 5 GB in chat. Files too large to preview show an Open button.
- Links to sessions, settings, triggers, Flows and chats now open inside Maskin instead of Safari.
- Chat: touch and hold a word to select it. Message actions now sit behind a More button next to each message.
