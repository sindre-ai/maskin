Native Maskin LLM Subscription — OpenRouter Routing, Billing Data Model, Usage Tracking

main ← bet/native-llm-subscriptionOpen PR

Adds a Maskin-funded LLM tier so workspaces can run agents without supplying their own Anthropic credentials. Introduces a billing data model (plan/Stripe/caps stored in workspace.settings.billing), routes paid/trial plans through Maskin's OpenRouter account, enforces hard-cap limits before session creation (HTTP 402 on breach), implements Stripe checkout + webhook lifecycle, and adds a mutual-exclusion layer that auto-cancels a paid subscription when the user adds a BYO key.
